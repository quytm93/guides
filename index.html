Phần 0 · Nền tảng Swift

Gốc rễ của mọi bài sau — nắm chắc thì hết "học vẹt".

Bỏ qua phần này bạn vẫn gõ được code — nhưng sẽ học vẹt. Nắm nền tảng, mọi bài sau nhẹ tênh:

🧠
Value vs Reference — struct được sao chép & thường nằm ở stack (rất nhanh); class chia sẻ & nằm ở heap. Chọn đúng → tránh bug "sửa chỗ này hỏng chỗ kia".
⚡
Tốc độ & bộ nhớ — stack cấp phát/thu hồi gần như tức thì; heap tốn hơn & cần ARC. Nền cho Bài 18 (ARC, retain cycle).
🛡
An toàn với Optionals — nil được kiểm soát → ít crash (Bài S2).
🧩
Hiểu vì sao SwiftUI viết vậy — View là struct, dùng protocol & closure khắp nơi (Bài S4).
