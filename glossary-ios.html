1 · Ngôn ngữ Swift

Swift language · Nền tảng của mọi dòng code iOS

struct

Là gì: Kiểu “giá trị” (value type) — khi gán/truyền đi sẽ được sao chép.

Dùng khi: Mặc định nên dùng cho model dữ liệu & View trong SwiftUI; an toàn, không chia sẻ trạng thái ngầm.

class

Là gì: Kiểu “tham chiếu” (reference type) — nhiều biến cùng trỏ tới một thực thể.

Dùng khi: Cần chia sẻ trạng thái, kế thừa, hoặc dùng với @Observable cho ViewModel.

Value vs Reference type

Là gì: struct/enum sao chép giá trị; class chia sẻ tham chiếu.

Dùng khi: Hiểu để tránh bug “sửa chỗ này, đổi luôn chỗ kia” và rò rỉ bộ nhớ.

enum

Là gì: Kiểu liệt kê các trạng thái cố định, có thể kèm dữ liệu (associated values).

Dùng khi: Mô tả trạng thái màn hình (loading/loaded/error), lựa chọn, kết quả.

protocol

Là gì: Bản “hợp đồng” liệt kê thuộc tính/hàm mà kiểu tuân theo phải có.

Dùng khi: Trừu tượng hoá để thay thế/giả lập (mock) khi test, vd View, Codable.

extension

Là gì: Bổ sung hàm/thuộc tính cho một kiểu đã có (kể cả của Apple).

Dùng khi: Tách code cho gọn, thêm tiện ích cho String, Date, View…

Optional ? / !

Là gì: Kiểu “có thể có hoặc nil”. ! là ép mở (force unwrap) — dễ crash.

Dùng khi: Mô tả giá trị có thể vắng; tránh !, ưu tiên mở an toàn.

if let / guard let

Là gì: Cách mở Optional an toàn. guard thoát sớm nếu nil.

Dùng khi: Kiểm tra dữ liệu đầu vào trước khi dùng, thay cho force unwrap.

Closure

Là gì: Khối code có thể truyền đi như một giá trị (hàm vô danh).

Dùng khi: Callback, completion handler, action của Button, biến đổi mảng (map/filter).

[weak self]

Là gì: Danh sách bắt giữ (capture list) giữ self dạng weak trong closure.

Dùng khi: Closure sống lâu (network, timer) để tránh retain cycle & rò rỉ bộ nhớ.

Generics

Là gì: Viết code dùng chung cho nhiều kiểu với tham số kiểu <T>.

Dùng khi: Tạo hàm/kiểu tái sử dụng, vd Array<T>, hàm decode chung.

Property Wrapper

Là gì: Cú pháp @... gói logic quanh một thuộc tính.

Dùng khi: Hiểu bản chất của @State, @AppStorage, @Observable…

Codable

Là gì: Giao thức cho phép mã hoá/giải mã giữa Swift & JSON (Encodable + Decodable).

Dùng khi: Đọc dữ liệu API hoặc lưu/đọc file JSON.

Result

Là gì: Kiểu chứa .success(value) hoặc .failure(error).

Dùng khi: Biểu diễn kết quả có thể lỗi (thường gặp trong API kiểu callback cũ).

Error handling throws

Là gì: Cơ chế báo lỗi với throw, bắt bằng do/catch, gọi với try.

Dùng khi: Hàm có thể thất bại: đọc file, decode JSON, gọi mạng.

Equatable / Hashable

Là gì: So sánh bằng nhau (==) và tạo mã băm để dùng trong Set/Dictionary.

Dùng khi: So sánh model, dùng làm key, tối ưu cập nhật danh sách.

Identifiable

Là gì: Giao thức yêu cầu mỗi phần tử có id duy nhất.

Dùng khi: Bắt buộc cho dữ liệu hiển thị trong List / ForEach.

2 · Concurrency (Swift 6)

Concurrency · Chạy song song an toàn — mặc định của Swift hiện đại

async / await

Là gì: Cú pháp viết code bất đồng bộ tuần tự, dễ đọc như code thường.

Dùng khi: Gọi mạng, đọc file, mọi tác vụ chờ lâu — thay cho completion handler.

Task

Là gì: Một đơn vị công việc bất đồng bộ, cầu nối từ code đồng bộ sang async.

Dùng khi: Khởi chạy việc async từ Button action hoặc .task của View.

async let

Là gì: Chạy nhiều việc async song song rồi await kết quả sau.

Dùng khi: Tải nhiều tài nguyên cùng lúc cho nhanh (vd 2 API độc lập).

TaskGroup

Là gì: Nhóm động nhiều task con chạy song song, gom kết quả lại.

Dùng khi: Số lượng việc không cố định, vd tải N ảnh trong danh sách.

actor

Là gì: Kiểu tham chiếu tự bảo vệ trạng thái khỏi truy cập đồng thời.

Dùng khi: Chia sẻ dữ liệu giữa nhiều task mà không lo data race (vd cache).

@MainActor

Là gì: Đánh dấu code phải chạy trên luồng chính (UI).

Dùng khi: Cập nhật giao diện; ViewModel cập nhật state hiển thị.

Sendable

Là gì: Nhãn cho biết kiểu an toàn để truyền qua ranh giới luồng/concurrency.

Dùng khi: Trình biên dịch Swift 6 yêu cầu khi chia sẻ dữ liệu giữa các task.

Data race / Strict concurrency

Là gì: Hai luồng cùng đọc/ghi một dữ liệu → lỗi khó lường. Swift 6 bật kiểm tra mặc định.

Dùng khi: Hiểu lý do compiler bắt lỗi concurrency — để viết code an toàn từ đầu.

@escaping

Là gì: Closure “thoát” khỏi hàm, được giữ lại để gọi sau.

Dùng khi: Gặp ở completion handler kiểu cũ; là nơi dễ tạo retain cycle.

DispatchQueue (GCD) Kế thừa

Là gì: API quản lý luồng cũ (Grand Central Dispatch).

Dùng khi: Đọc code cũ; với code mới hãy ưu tiên async/await + actor.

3 · Bộ nhớ & hiệu năng

Memory & performance · Tránh crash, rò rỉ bộ nhớ & giật lag

ARC

Là gì: Automatic Reference Counting — đếm tham chiếu để tự giải phóng bộ nhớ.

Dùng khi: Luôn chạy ngầm; hiểu nó để biết vì sao cần weak.

Retain cycle

Là gì: Hai đối tượng giữ tham chiếu mạnh lẫn nhau → không bao giờ được giải phóng.

Dùng khi: Nhận diện & phá bằng [weak self] / weak / unowned.

weak / unowned

Là gì: Tham chiếu không làm tăng bộ đếm. weak thành nil; unowned giả định luôn tồn tại.

Dùng khi: Phá retain cycle ở delegate, closure, quan hệ cha–con.

Memory leak

Là gì: Bộ nhớ cấp phát nhưng không được thu hồi → app phình to dần.

Dùng khi: Phát hiện bằng Instruments (Leaks) khi app ngày càng nặng.

Instruments

Là gì: Bộ công cụ đo hiệu năng của Xcode (Time Profiler, Leaks, Allocations…).

Dùng khi: Truy tìm chậm, rò rỉ, dùng CPU/bộ nhớ quá mức.

Hang / Watchdog 0x8badf00d

Là gì: Hệ thống kết liễu app khi luồng chính bị khoá quá lâu (mã “ate bad food”).

Dùng khi: Hiểu để đẩy việc nặng khỏi luồng chính, tránh “đơ” màn hình.

Jetsam (OOM)

Là gì: Cơ chế iOS kết liễu app dùng quá nhiều RAM (out-of-memory).

Dùng khi: Hiểu khi xử lý ảnh lớn/nhiều dữ liệu — cần giảm/giải phóng bộ nhớ.

4 · App & vòng đời

App & lifecycle · Cấu trúc & trạng thái của một ứng dụng

App / Scene

Là gì: App là điểm vào; Scene (vd WindowGroup) là một cửa sổ giao diện.

Dùng khi: Khai báo cấu trúc gốc của ứng dụng SwiftUI.

@main

Là gì: Đánh dấu struct là điểm khởi động của app.

Dùng khi: Đặt trên struct tuân theo App — chỉ một nơi duy nhất.

ScenePhase

Là gì: Trạng thái app: active / inactive / background.

Dùng khi: Lưu dữ liệu, tạm dừng timer khi app vào nền.

Background Modes

Là gì: Năng lực (Capability) cho phép app tiếp tục chạy ở nền: audio, location, voip, processing…

Dùng khi: Bật trong Signing & Capabilities khi app cần hoạt động khi không hiển thị (vd phát nhạc nền).

beginBackgroundTask

Là gì: Xin thêm ~30 giây để hoàn tất việc dở khi app vừa vào nền; phải gọi endBackgroundTask khi xong.

Dùng khi: Lưu nốt dữ liệu/đóng kết nối lúc vào nền — quên kết thúc đúng hạn sẽ bị kill 0xdead10cc.

BGTaskScheduler

Là gì: Lên lịch chạy nền sau này: BGAppRefreshTask (làm mới nhanh) & BGProcessingTask (việc nặng/khi sạc).

Dùng khi: Đồng bộ dữ liệu, dọn dẹp, tải trước nội dung — hệ thống tự chọn thời điểm theo “ngân sách” pin/mạng.

AppDelegate

Là gì: Lớp xử lý sự kiện vòng đời kiểu UIKit cũ.

Dùng khi: Cần móc nối Push/SDK bên thứ ba qua @UIApplicationDelegateAdaptor.

Bundle

Là gì: Gói chứa app đã build: code, ảnh, plist, tài nguyên.

Dùng khi: Đọc file kèm app, ảnh, file cấu hình qua Bundle.main.

Info.plist

Là gì: File cấu hình app: tên, version, quyền (camera, vị trí…).

Dùng khi: Khai báo quyền truy cập & thiết lập app trước khi phát hành.

Entitlements

Là gì: Khai báo năng lực đặc biệt: Push, iCloud, App Groups…

Dùng khi: Bật tính năng cần Apple cấp quyền (Capabilities trong Xcode).

Target vs Scheme

Là gì: Target = sản phẩm build (app/extension); Scheme = cách build/run target đó.

Dùng khi: Tách môi trường Dev/Staging/Prod, thêm widget/extension.

5 · Dữ liệu & lưu trữ

Data & storage · Lấy dữ liệu từ mạng & lưu xuống máy

URLSession

Là gì: API chuẩn để gọi mạng (HTTP) trong iOS.

Dùng khi: Tải JSON/ảnh từ API, kết hợp async/await + Codable.

JSON & JSONDecoder

Là gì: Định dạng dữ liệu phổ biến; JSONDecoder chuyển JSON → struct Codable.

Dùng khi: Giải mã phản hồi API thành model Swift.

SwiftData iOS 17+

Là gì: Framework lưu trữ hiện đại với @Model, @Query, ModelContext.

Dùng khi: Cơ sở dữ liệu trong app — thay thế Core Data cho dự án mới.

UserDefaults

Là gì: Kho lưu key–value nhỏ, bền sau khi tắt app.

Dùng khi: Lưu cài đặt, lựa chọn nhỏ (thường qua @AppStorage).

FileManager

Là gì: API đọc/ghi/quản lý file & thư mục trong sandbox của app.

Dùng khi: Lưu file lớn: ảnh, tài liệu, cache xuống đĩa.

Keychain

Là gì: Kho lưu trữ được mã hoá, an toàn của hệ thống.

Dùng khi: Lưu token, mật khẩu, dữ liệu nhạy cảm (không để trong UserDefaults).

Core Data Kế thừa

Là gì: Framework lưu trữ truyền thống, mạnh nhưng phức tạp hơn SwiftData.

Dùng khi: Bảo trì app cũ; dự án mới ưu tiên SwiftData.

6 · Framework & dịch vụ

Frameworks & services · Các bộ công cụ & tính năng hệ thống

Foundation

Là gì: Thư viện nền: String, Date, URL, Data, số học…

Dùng khi: Hầu như mọi file đều dùng — nền tảng của Swift trên Apple.

UIKit (interop)

Là gì: Framework UI thế hệ trước SwiftUI (dựa trên view tường minh).

Dùng khi: Nhúng thành phần chưa có trong SwiftUI qua UIViewRepresentable.

Combine Kế thừa

Là gì: Framework xử lý luồng sự kiện theo thời gian (reactive).

Dùng khi: Đọc code cũ; stack mới dùng @Observable + async/await.

UserNotifications / APNs

Là gì: UNUserNotificationCenter cho thông báo cục bộ; APNs cho thông báo đẩy từ server.

Dùng khi: Nhắc nhở người dùng, gửi tin tức/cập nhật. Phải xin quyền (requestAuthorization) trước, nếu không lịch thông báo sẽ âm thầm thất bại.

Local Notification (Reminder)

Là gì: Thông báo hẹn giờ ngay trên máy qua UNCalendarNotificationTrigger / UNTimeIntervalNotificationTrigger — không cần server.

Dùng khi: Đặt lời nhắc, báo thức, nhắc lịch — đặt identifier để cập nhật/huỷ, chú ý giới hạn 64 thông báo đang chờ.

WidgetKit

Là gì: Framework tạo widget màn hình chính/khoá & Live Activities.

Dùng khi: Hiển thị thông tin nhanh ngoài app (thời tiết, tiến độ…).

MapKit

Là gì: Framework hiển thị bản đồ, ghim vị trí, chỉ đường.

Dùng khi: App cần bản đồ, định vị, tìm địa điểm.

StoreKit

Là gì: Framework mua trong ứng dụng & gói đăng ký (StoreKit 2).

Dùng khi: Bán vật phẩm, mở khoá tính năng, subscription.

String Catalog

Là gì: Hệ thống quản lý chuỗi đa ngôn ngữ (.xcstrings) của Xcode 15+.

Dùng khi: Bản địa hoá (localization) app sang nhiều ngôn ngữ.

7 · Công cụ Xcode 26

Xcode 26 tooling · Môi trường làm việc của lập trình viên iOS

Xcode

Là gì: IDE chính thức của Apple để viết, build & debug app.

Dùng khi: Toàn bộ quá trình phát triển; bản hiện tại là Xcode 26.

Simulator

Là gì: Trình giả lập iPhone/iPad chạy ngay trên máy Mac.

Dùng khi: Thử app nhanh mà không cần thiết bị thật.

Previews #Preview

Là gì: Bản xem trước SwiftUI cập nhật trực tiếp trong Xcode.

Dùng khi: Dựng & tinh chỉnh giao diện mà không cần build lại app.

Swift Package Manager

Là gì: Trình quản lý thư viện phụ thuộc (SPM) tích hợp trong Xcode.

Dùng khi: Thêm thư viện bên thứ ba qua URL Git.

LLDB / Debugger

Là gì: Trình gỡ lỗi: đặt breakpoint, xem biến, chạy lệnh po.

Dùng khi: Tìm nguyên nhân bug khi app chạy sai.

TestFlight

Là gì: Nền tảng của Apple để phát hành bản beta cho người thử nghiệm.

Dùng khi: Cho QA/người dùng thử trước khi lên App Store.

Signing & Provisioning

Là gì: Chứng chỉ & profile xác thực app được phép chạy/phân phối.

Dùng khi: Chạy trên máy thật, archive & nộp App Store.
