Thông báo & Push

Nhắc nhở người dùng đúng lúc: lên lịch thông báo ngay trong app, và hiểu cách thông báo đẩy từ máy chủ hoạt động.

Bài 15 UserNotifications · APNs ~25 phút
Nhấn → hoặc Space để bắt đầu
Trong bài này

Bạn sẽ học được gì

  • Phân biệt thông báo cục bộ & đẩy (push)
  • Xin quyền gửi thông báo
  • Tạo & lên lịch một thông báo cục bộ
  • Hiểu APNs & device token (mức tổng quan)
  • Bật capability Push trong Xcode 26

Cần nắm async/await (Bài 8). Thông báo cục bộ làm được ngay; push cần máy chủ + tài khoản trả phí.

Hai loại

Cục bộ so với Đẩy

📍 Cục bộ (Local)

  • Do chính app lên lịch
  • Không cần internet hay máy chủ
  • Vd: nhắc uống nước, báo thức, hẹn giờ

☁️ Đẩy (Remote / Push)

  • Gửi từ máy chủ của bạn qua APNs
  • Cần device token + tài khoản trả phí
  • Vd: tin nhắn mới, khuyến mãi

Bài này tập trung vào thông báo cục bộ (làm được ngay), rồi giới thiệu push ở mức tổng quan.

Bước đầu tiên

Xin quyền gửi thông báo

iOS luôn hỏi người dùng trước. Phải xin quyền, thường khi app khởi động:

import UserNotifications

func xinPhep() async {
    _ = try? await UNUserNotificationCenter.current()
        .requestAuthorization(options: [.alert, .sound, .badge])
}

.alert (banner) · .sound (âm thanh) · .badge (số đỏ trên icon). Người dùng có thể từ chối — hãy tôn trọng.

Tạo nội dung

Soạn một thông báo cục bộ

let content = UNMutableNotificationContent()
content.title = "Nhắc nhở ⏰"
content.body  = "Đến giờ học iOS rồi!"
content.sound = .default

UNMutableNotificationContent là "nội dung" hiện ra: tiêu đề, nội dung, âm thanh, badge… Soạn xong, ta cần nói khi nào hiện.

Khi nào hiện?

Trigger & lên lịch

// Hiện sau 5 giây
let trigger = UNTimeIntervalNotificationTrigger(
    timeInterval: 5, repeats: false)

let yeuCau = UNNotificationRequest(
    identifier: UUID().uuidString,
    content: content, trigger: trigger)

try? await UNUserNotificationCenter.current().add(yeuCau)

Cũng có UNCalendarNotificationTrigger để hẹn đúng giờ (vd 7h sáng mỗi ngày). Mỗi yêu cầu cần một identifier riêng.

Tổng quan

Thông báo đẩy hoạt động ra sao?

  1. 1
    App xin quyền & nhận một device token (địa chỉ của thiết bị).
  2. 2
    App gửi token đó về máy chủ của bạn.
  3. 3
    Khi cần báo, máy chủ gửi tin tới APNs (Apple Push Notification service).
  4. 4
    APNs đẩy thông báo tới đúng iPhone — kể cả khi app đang tắt.

Push cần máy chủ + Developer Program. Phần server nằm ngoài SwiftUI — nhưng hiểu luồng này là đủ để bắt đầu.

Khi người dùng tương tác

Chạm vào thông báo & app đang mở

  • Mặc định: app đang tắt → chạm thông báo sẽ mở app
  • App đang mở → muốn vẫn hiện banner cần một delegate
  • Đặt UNUserNotificationCenter.current().delegate để xử lý chạm & hiển thị
// Cho phép hiện banner ngay cả khi app đang mở
func userNotificationCenter(_ c: UNUserNotificationCenter,
     willPresent n: UNNotification) async
     -> UNNotificationPresentationOptions { [.banner, .sound] }

Delegate phải là một class kế thừa NSObject & conform UNUserNotificationCenterDelegate, và phải gán sớm (vd trong init của app). Người mới có thể để dành phần này.

Code hoàn chỉnh

Nhắc nhở cục bộ — chép là chạy ✅

import SwiftUI
import UserNotifications

struct ReminderView: View {
    @State private var trangThai = "Chưa đặt nhắc nhở"

    var body: some View {
        VStack(spacing: 20) {
            Text(trangThai)
            Button("Nhắc tôi sau 5 giây") {
                Task { await datLich() }
            }
            .buttonStyle(.borderedProminent)
        }
        .padding()
        .task { await xinPhep() }
    }

    func xinPhep() async {
        _ = try? await UNUserNotificationCenter.current()
            .requestAuthorization(options: [.alert, .sound, .badge])
    }

    func datLich() async {
        let content = UNMutableNotificationContent()
        content.title = "Nhắc nhở ⏰"
        content.body  = "Đến giờ học iOS rồi!"
        content.sound = .default
        let trigger = UNTimeIntervalNotificationTrigger(
            timeInterval: 5, repeats: false)
        let yeuCau = UNNotificationRequest(
            identifier: UUID().uuidString, content: content, trigger: trigger)
        try? await UNUserNotificationCenter.current().add(yeuCau)
        trangThai = "Sẽ nhắc sau 5 giây ✅"
    }
}

Cùng ôn lại

Những gì bạn đã biết

  • Cục bộ: app tự lên lịch · Đẩy: máy chủ gửi qua APNs
  • Phải xin quyền với requestAuthorization
  • Soạn UNMutableNotificationContent + chọn trigger (thời gian/lịch)
  • Thêm bằng UNUserNotificationCenter.current().add(...)
  • Push cần capability + máy chủ; delegate để xử lý chạm

Thông báo đúng lúc giữ chân người dùng — nhưng spam thông báo sẽ khiến họ tắt app. Dùng tinh tế!
