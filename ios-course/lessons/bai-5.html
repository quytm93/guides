Cái khung

Bọc trong NavigationStack

NavigationStack là "chồng màn hình": màn mới đẩy vào, bấm Back thì lấy ra.

NavigationStack {
    VStack {
        Text("Màn hình chính")
    }
    .navigationTitle("Trang chủ")
}

.navigationTitle đặt tiêu đề hiện trên thanh trên cùng. Mọi điều hướng phải nằm bên trong một NavigationStack.

Chuyển màn hình

Chạm để đi với NavigationLink

NavigationLink cần hai phần: nhãn để chạm, và màn hình đích để mở.

NavigationStack {
    NavigationLink("Xem chi tiết") {
        DetailView()        // màn hình đích
    }
    .navigationTitle("Trang chủ")
}

Chạm "Xem chi tiết" → DetailView trượt vào, kèm nút Back tự động ở góc trái. Không cần bạn tự làm nút quay lại!

Màn hình đích

Màn hình chi tiết chỉ là… một View

Không có gì đặc biệt — vẫn là một struct tuân theo View như mọi khi:

struct DetailView: View {
    var body: some View {
        Text("Đây là màn hình chi tiết 🎉")
            .navigationTitle("Chi tiết")
    }
}

Mọi thứ học ở Bài 1–4 (Stack, List, @State…) đều dùng được trong màn hình đích.

Mang theo dữ liệu

Truyền dữ liệu sang màn đích

Cho màn hình chi tiết một thuộc tính, rồi truyền giá trị vào khi tạo nó:

struct DetailView: View {
    let ten: String          // nhận dữ liệu vào đây

    var body: some View {
        Text("Chi tiết của \(ten)")
    }
}

// Khi điều hướng, truyền giá trị:
NavigationLink("Táo") {
    DetailView(ten: "Táo")
}

Đây chính là cách màn hình chi tiết biết "đang xem mục nào".

Mẫu kinh điển

Danh sách điều hướng được

Ghép List + ForEach (Bài 4) với NavigationLink:

let trais = ["Táo", "Chuối", "Cam"]

NavigationStack {
    List(trais, id: \.self) { trai in
        NavigationLink(trai) {
            DetailView(ten: trai)
        }
    }
    .navigationTitle("Trái cây")
}

Mỗi hàng tự thành một liên kết. Bấm "Chuối" → mở chi tiết của Chuối. Đây là bộ khung của vô số app iOS.

Quay lại

Nút Back hoạt động thế nào?

✅ Tự động

  • Nút Back & vuốt-để-quay-lại có sẵn
  • Bạn không phải viết gì thêm

🎚 Khi cần chủ động

  • Dùng @Environment(\.dismiss)
  • Gọi dismiss() để tự đóng màn hình
@Environment(\.dismiss) private var dismiss
// đặt trong struct của màn đích:
Button("Xong") { dismiss() }   // tự quay lại
Cùng ôn lại

Những gì bạn đã biết

  • NavigationStack là khung chứa cho mọi điều hướng
  • NavigationLink = chạm để mở một màn hình mới
  • .navigationTitle đặt tiêu đề thanh trên
  • Truyền dữ liệu bằng cách cho màn đích một thuộc tính
  • List + NavigationLink = mẫu "danh sách → chi tiết"

Bạn vừa dựng được khung xương của một app nhiều màn hình hoàn chỉnh!

import SwiftUI

struct FruitListView: View {
    let trais = ["Táo", "Chuối", "Cam"]

    var body: some View {
        NavigationStack {
            List(trais, id: \.self) { trai in
                NavigationLink(trai) {
                    DetailView(ten: trai)
                }
            }
            .navigationTitle("Trái cây")
        }
    }
}

struct DetailView: View {
    let ten: String

    var body: some View {
        Text("Chi tiết của \(ten) 🎉")
            .navigationTitle(ten)
    }
}
