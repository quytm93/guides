Model dữ liệu với struct

Tự tạo kiểu dữ liệu của riêng bạn để mỗi mục mang nhiều thông tin — nền tảng cho mọi app danh sách thật sự.

Cần xong Bài 1–6. Bạn sẽ dùng lại List/ForEach (Bài 4) và @State (Bài 3).

Vấn đề

Một mục cần nhiều thông tin

Ở Bài 4, mỗi mục chỉ là một chuỗi. Nhưng một "việc cần làm" thật có tên và trạng thái xong/chưa:

let viecs = ["Học Swift", "Tập thể dục"]
// Làm sao biết việc nào đã xong? 🤔
// Một chuỗi không chứa nổi nhiều thông tin.

Ta cần một "khuôn" gói nhiều mẩu thông tin lại thành một mục. Đó là việc của struct.

Lời giải

Tự tạo kiểu với struct

struct gói nhiều thuộc tính thành một kiểu dữ liệu của riêng bạn:

struct Viec {
    let ten: String
    var xong: Bool
}

// Tạo một việc cụ thể:
let v = Viec(ten: "Học Swift", xong: false)
print(v.ten)   // đọc thuộc tính: "Học Swift"

Quen chứ? View bạn viết từ Bài 1 cũng là struct. Giờ bạn tạo struct để chứa dữ liệu.

Gom lại

Một mảng các model

let danhSach = [
    Viec(ten: "Học Swift", xong: true),
    Viec(ten: "Tập thể dục", xong: false),
    Viec(ten: "Đọc sách", xong: false),
]

Giờ mỗi phần tử mang cả tên lẫn trạng thái. Nhưng để đưa vào List, SwiftUI cần biết cách phân biệt từng mục…

Danh tính

Cho model một id

Tuân theo Identifiable: thêm thuộc tính id để mỗi mục là duy nhất:

struct Viec: Identifiable {
    let id = UUID()      // tự sinh mã duy nhất
    let ten: String
    var xong: Bool
}

UUID() tạo một mã ngẫu nhiên không trùng lặp. Nhờ id, SwiftUI biết mục nào là mục nào khi danh sách thay đổi.

Hiển thị

List gọn hơn nhờ Identifiable

Khi model đã Identifiable, bạn bỏ luôn id: \.self (Bài 4):

List(danhSach) { viec in
    HStack {
        Image(systemName: viec.xong
            ? "checkmark.circle.fill" : "circle")
        Text(viec.ten)
    }
}

viec.xong ? A : B chọn icon theo trạng thái. Mỗi hàng giờ đọc thẳng các thuộc tính của model.

Sống động

Thêm & xoá mục

Cho mảng vào @State (Bài 3) để danh sách tự cập nhật khi đổi:

@State private var danhSach = [
    Viec(ten: "Học Swift", xong: false)
]

Button("Thêm việc") {
    danhSach.append(Viec(ten: "Việc mới", xong: false))
}

.append(...) thêm phần tử; danh sách @State đổi → giao diện tự vẽ lại. Để xoá, đặt .onDelete trên một ForEach bên trong List (xem code mẫu cuối bài) — không gắn thẳng vào List(data).

Cùng ôn lại

Những gì bạn đã biết

  • struct gói nhiều thuộc tính thành kiểu của riêng bạn
  • Tạo mục: Viec(ten:..., xong:...); đọc bằng v.ten
  • Một mảng model chứa danh sách giàu thông tin
  • Identifiable + id = UUID() cho mỗi mục danh tính
  • List(danhSach) gọn hơn; @State để thêm/xoá

Đây là bộ khung dữ liệu của hầu hết app thật: model → mảng → danh sách.

Thử thách: kết hợp Bài 5 — chạm một mục để mở màn hình chi tiết của model đó.

Code hoàn chỉnh

App "Việc cần làm" — chép là chạy ✅

import SwiftUI

struct Viec: Identifiable {
    let id = UUID()
    let ten: String
    var xong: Bool
}

struct ViecListView: View {
    @State private var danhSach = [
        Viec(ten: "Học Swift", xong: true),
        Viec(ten: "Tập thể dục", xong: false),
    ]

    var body: some View {
        NavigationStack {
            List {
                ForEach(danhSach) { viec in
                    HStack {
                        Image(systemName: viec.xong
                            ? "checkmark.circle.fill" : "circle")
                        Text(viec.ten)
                    }
                }
                .onDelete { danhSach.remove(atOffsets: $0) }
            }
            .navigationTitle("Việc cần làm")
            .toolbar {
                Button("Thêm") {
                    danhSach.append(Viec(ten: "Việc mới", xong: false))
                }
            }
        }
    }
}

#Preview {
    ViecListView()
}
