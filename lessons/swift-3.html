Collections & Điều khiển luồng

Chứa nhiều giá trị cùng lúc (mảng, từ điển) và ra quyết định trong code (if, switch, vòng lặp).

Nền tảng · S3 Array · for · switch ~22 phút
Nhấn → hoặc Space để bắt đầu
Trong bài này

Bạn sẽ học được gì

  • Array (mảng) — danh sách giá trị
  • Thao tác mảng: thêm, đếm, truy cập, lặp
  • Dictionary (từ điển) — cặp khoá–giá trị
  • Điều kiện if / else & switch
  • Enum — tập hợp lựa chọn cố định

Mảng & vòng lặp là nền của List/ForEach (Bài 4); switch/enum bạn gặp ở Bài 17.

Danh sách

Mảng — Array

var trais = ["Táo", "Chuối", "Cam"]

trais[0]          // "Táo"  (đếm từ 0)
trais.count       // 3
trais.append("Xoài")  // thêm vào cuối
trais.isEmpty     // false

Mảng giữ nhiều giá trị cùng kiểu, có thứ tự. Truy cập bằng chỉ số [i], bắt đầu từ 0.

Lặp qua

Vòng lặp for

for trai in trais {
    print("Tôi thích \(trai)")
}

// Lặp theo số lần với range:
for i in 1...3 {
    print("Lần \(i)")   // 1, 2, 3
}

1...3 là dải bao gồm 3; 0..<3 là không gồm 3 (0,1,2). Bạn đã thấy 0..<1000 ở Bài 16.

Cặp khoá–giá trị

Từ điển — Dictionary

var diem = ["An": 9, "Bình": 7]

diem["An"]            // 9 (kiểu Int?, vì có thể không có)
diem["Chi"] = 8       // thêm cặp mới

Tra cứu bằng khoá thay vì chỉ số. Lưu ý diem["An"] là Optional (S2) — vì khoá có thể không tồn tại.

Ra quyết định

Điều kiện if / else

let diem = 8

if diem >= 9 {
    print("Giỏi")
} else if diem >= 7 {
    print("Khá")
} else {
    print("Cố lên")
}

So sánh: == bằng, != khác, > < >= <=. Nối điều kiện: && (và), || (hoặc).

Nhiều nhánh gọn

Chọn với switch

let thu = 3

switch thu {
case 1: print("Thứ Hai")
case 7: print("Chủ Nhật")
default: print("Ngày thường")
}

switch gọn hơn nhiều if/else khi có nhiều trường hợp. Trong Swift phải bao mọi trường hợp — dùng default cho phần còn lại.

Lựa chọn cố định

Enum — tập lựa chọn

enum HuongDi {
    case trai, phai, len, xuong
}

let h = HuongDi.trai

switch h {
case .trai:  print("Rẽ trái")
case .phai:  print("Rẽ phải")
default:    print("Đi thẳng")
}

enum giới hạn giá trị trong một tập cố định, an toàn. .active/.background ở Bài 17 chính là enum ScenePhase.

Code hoàn chỉnh

Chạy trong Playground ✅

let diemSo = ["An": 9, "Bình": 7, "Chi": 5]

for (ten, diem) in diemSo {
    let xepLoai: String
    switch diem {
    case 9...10: xepLoai = "Giỏi"
    case 7..<9:  xepLoai = "Khá"
    default:      xepLoai = "Cố lên"
    }
    print("\(ten): \(diem) → \(xepLoai)")
}

Lặp qua từ điển, dùng switch với dải số để xếp loại. Gói gọn cả mảng/từ điển, vòng lặp & điều kiện.

Cùng ôn lại

Những gì bạn đã biết

  • Array giữ danh sách; truy cập [i], .append, .count
  • for x in ... lặp; dải 1...3 / 0..<3
  • Dictionary tra theo khoá (kết quả là Optional)
  • if/else & switch (phải bao mọi trường hợp)
  • Enum = tập lựa chọn cố định, an toàn
