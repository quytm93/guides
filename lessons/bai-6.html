Cần xong Bài 1–5. Bạn sẽ thấy @AppStorage dùng y hệt @State — chỉ khác là nó nhớ mãi.

Vấn đề

Dữ liệu "bốc hơi" khi tắt app

Ở Bài 3, app đếm số dùng @State. Thử bấm lên 10 rồi… tắt app mở lại:

@State private var soLan = 0
// Bấm tới 10... tắt app... mở lại → về 0 😢

@State chỉ sống trong bộ nhớ tạm. Tắt app là mất. Ta cần nơi cất giữ lâu dài trên máy.

Lời giải

Gặp gỡ @AppStorage

Đổi @State thành @AppStorage và đặt cho nó một "chìa khoá" (key) — thế là xong!

@AppStorage("soLan") var soLan = 0
//          ↑ chìa khoá lưu trữ   ↑ giá trị mặc định

Mỗi lần soLan đổi, nó tự lưu xuống máy. Mở lại app → tự đọc lên đúng giá trị cũ. Giao diện vẫn cập nhật y như @State.

Ghép lại

App đếm số… biết nhớ

struct CounterView: View {
    @AppStorage("soLan") var soLan = 0

    var body: some View {
        VStack(spacing: 20) {
            Text("\(soLan)")
                .font(.system(size: 80, weight: .bold))
            Button("Bấm +1") { soLan += 1 }
                .buttonStyle(.borderedProminent)
        }
    }
}

Giống hệt Bài 3, chỉ đổi 1 dòng! Giờ bấm tới 10, tắt app, mở lại → vẫn là 10. 🎉

Phía sau hậu trường

Nó cất ở đâu? UserDefaults

@AppStorage ghi vào UserDefaults — một "sổ tay" nhỏ của app để lưu các thiết lập đơn giản.

🔑

Dạng key–value

Mỗi giá trị gắn với một "chìa khoá" chữ, như từ điển.

💾

Tự lưu xuống đĩa

Tồn tại qua các lần mở/tắt app.

⚡️

Nhanh & nhẹ

Hợp cho dữ liệu nhỏ, không hợp dữ liệu lớn.

Trùng key = trùng ô lưu. Dùng "soLan" ở nhiều nơi → chúng chia sẻ cùng một giá trị.

Ví dụ thực tế

Ghi nhớ lựa chọn người dùng

@AppStorage tuyệt cho phần "Cài đặt" — lưu được cả chữ lẫn lựa chọn:

// Nhớ tên (String)
@AppStorage("ten") var ten = ""

TextField("Tên", text: $ten)
// Chế độ tối (Bool)
@AppStorage("choDoToi") var choDoToi = false

Toggle("Chế độ tối", isOn: $choDoToi)

Nhớ dấu $ (Bài 3) để TextField/Toggle đọc–ghi được. Gõ tên hay bật chế độ tối → lần sau mở app vẫn nhớ.

Lưu được gì?

Các kiểu dữ liệu hợp lệ

✅ Dùng tốt

  • String — chữ (tên, ghi chú ngắn)
  • Int, Double — số
  • Bool — bật/tắt

⚠️ Tránh

  • Danh sách lớn, ảnh, file
  • Dữ liệu phức tạp (mảng struct…)
  • → để dành cho bài sau (file / cơ sở dữ liệu)

Quy tắc: thiết lập nhỏ → @AppStorage; dữ liệu lớn → công cụ mạnh hơn (học sau).

Cùng ôn lại

Những gì bạn đã biết

  • @State mất khi tắt app; @AppStorage thì nhớ mãi
  • Cú pháp: @AppStorage("key") var x = mặcĐịnh
  • Dùng y hệt @State — giao diện vẫn tự cập nhật
  • Lưu vào UserDefaults dạng key–value
  • Hợp dữ liệu nhỏ: String, Int, Double, Bool

Chỉ một thay đổi nhỏ mà app của bạn đã "thông minh" hơn hẳn.

Code hoàn chỉnh

Chép là chạy ✅

import SwiftUI

struct SettingsView: View {
    @AppStorage("soLan") var soLan = 0
    @AppStorage("choDoToi") var choDoToi = false

    var body: some View {
        VStack(spacing: 20) {
            Text("\(soLan)")
                .font(.system(size: 80, weight: .bold))
            Button("Bấm +1") { soLan += 1 }
                .buttonStyle(.borderedProminent)
            Toggle("Chế độ tối", isOn: $choDoToi)
                .padding(.horizontal)
        }
        .padding()
        .preferredColorScheme(choDoToi ? .dark : .light)
    }
}

#Preview {
    SettingsView()
}

Bấm vài lần, bật chế độ tối, tắt app rồi mở lại — mọi thứ vẫn được giữ nguyên. 💾
