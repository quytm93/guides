App tương tác đầu tiên

Cho màn hình "sống dậy": thêm nút bấm, lưu trạng thái thay đổi, và phản hồi mỗi cú chạm của người dùng.

Trong bài này

Bạn sẽ học được gì

  • Sự khác nhau giữa màn hình tĩnh và màn hình tương tác
  • Tạo một nút bấm với Button
  • Lưu dữ liệu thay đổi bằng @State
  • Hoàn thiện một app đếm số hoàn chỉnh
  • Nối ô nhập liệu hai chiều bằng binding (dấu $)

Cần học xong Bài 1 & 2 trước. Nếu bạn đã cài Xcode 26 và biết let, var, VStack thì bắt đầu được rồi!

Ý tưởng cốt lõi

Tĩnh so với tương tác

🖼 Màn hình tĩnh

  • Chỉ hiển thị, không đổi
  • Bài 1: Text("Chào iOS!")
  • Người dùng chạm → chẳng có gì xảy ra

⚡️ Màn hình tương tác

  • Phản hồi hành động của người dùng
  • Có dữ liệu thay đổi theo thời gian
  • Chạm → giao diện tự cập nhật

Bí quyết của tương tác = hành động (nút bấm) + dữ liệu thay đổi (state). Ta sẽ ghép hai thứ này lại.

Hành động

Nút bấm với Button

Button cần hai phần: việc cần làm khi bấm, và nhãn hiển thị trên nút.

Button {
    // việc cần làm khi bấm — chạy ở đây
    print("Bạn vừa bấm nút!")
} label: {
    Text("Bấm tôi đi")
}

Khối { } đầu là action (chạy khi bấm). Phần label: là cái người dùng nhìn thấy.

Vấn đề

Lưu con số đếm ở đâu?

Ta muốn đếm số lần bấm. Thử dùng var bình thường xem sao:

struct CounterView: View {
    var soLan = 0          // ❌ không hoạt động!

    var body: some View {
        Button("Đã bấm \(soLan) lần") {
            soLan += 1          // ❌ lỗi biên dịch
        }
    }
}

Hai lý do: (1) không sửa được biến trong body (View là struct, body chỉ đọc) → lỗi biên dịch; (2) dù sửa được, SwiftUI vẽ lại view liên tục nên giá trị bị "đặt lại". Ta cần cách nói: "hãy nhớ giá trị này".

Lời giải

Gặp gỡ @State

@State báo cho SwiftUI: hãy ghi nhớ giá trị này, và mỗi khi nó đổi thì vẽ lại màn hình.

@State private var soLan = 0

// Khi soLan đổi từ 0 → 1, SwiftUI tự động
// cập nhật mọi chỗ đang dùng soLan trên màn hình.

Đây là điều kỳ diệu của SwiftUI: bạn đổi dữ liệu, giao diện tự cập nhật theo. Bạn không phải tự tay vẽ lại gì cả.

Ghép lại

App đếm số hoàn chỉnh

import SwiftUI

struct CounterView: View {
    @State private var soLan = 0

    var body: some View {
        VStack(spacing: 20) {
            Text("\(soLan)")
                .font(.system(size: 80, weight: .bold))
            Button("Bấm +1") {
                soLan += 1          // ✅ chạy ngon!
            }
            .buttonStyle(.borderedProminent)
        }
    }
}

Bấm nút → soLan tăng → Text tự hiển thị số mới. Đó là app tương tác đầu tiên của bạn! 🎉

Thêm chút nữa

Hai nút, một state

Nhiều nút có thể cùng tác động lên một @State. Thêm nút "Đặt lại":

HStack {
    Button("Bấm +1") { soLan += 1 }
    Button("Đặt lại") { soLan = 0 }
        .tint(.red)
}

HStack xếp ngang (Bài 1 dùng VStack — xếp dọc). Mỗi nút đổi soLan theo cách riêng, giao diện luôn khớp.

Nối hai chiều

Ô nhập liệu & dấu $

Một số view (như TextField) cần đọc và ghi state. Dùng dấu $ để tạo binding — kết nối hai chiều.

@State private var ten = ""

VStack {
    TextField("Nhập tên của bạn", text: $ten)
    Text("Xin chào, \(ten)!")
}

$ten = "cho phép ô nhập thay đổi ten". Gõ tới đâu, dòng "Xin chào" cập nhật tới đó — tức thì.

Mô hình tư duy

Vòng lặp của tương tác

  1. 1
    Người dùng chạm một nút.
  2. 2
    Khối action chạy và đổi @State.
  3. 3
    SwiftUI thấy state đổi → vẽ lại body.
  4. 4
    Màn hình hiển thị giá trị mới. 🔁

Hãy nhớ một câu: "giao diện là hàm của state". Đổi state, giao diện tự theo. Bạn không bao giờ tự tay sửa view.

Code hoàn chỉnh

Chép là chạy ✅

import SwiftUI

struct CounterView: View {
    @State private var soLan = 0
    @State private var ten = ""

    var body: some View {
        VStack(spacing: 20) {
            Text("\(soLan)")
                .font(.system(size: 80, weight: .bold))
            HStack {
                Button("Bấm +1") { soLan += 1 }
                Button("Đặt lại") { soLan = 0 }
                    .tint(.red)
            }
            .buttonStyle(.borderedProminent)

            TextField("Nhập tên của bạn", text: $ten)
                .textFieldStyle(.roundedBorder)
                .padding(.horizontal)
            Text("Xin chào, \(ten)!")
        }
        .padding()
    }
}
