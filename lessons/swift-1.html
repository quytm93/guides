Kiểu dữ liệu & Hàm

Những viên gạch đầu tiên của ngôn ngữ Swift: chứa dữ liệu trong biến, và gói việc làm vào hàm.

Nền tảng · S1 let/var · func ~20 phút
Nên học cụm Nền tảng này trước Bài 3 · Nhấn → để bắt đầu
Trong bài này

Bạn sẽ học được gì

  • Biến (var) & hằng (let)
  • Các kiểu cơ bản: Int, Double, String, Bool
  • Swift tự đoán kiểu & khi nào tự khai báo
  • Chèn giá trị vào chuỗi (string interpolation)
  • Viết hàm: tham số, nhãn, giá trị trả về

Mẹo học: gõ thử mọi ví dụ trong Swift Playground (hoặc một Playground trong Xcode) để thấy kết quả ngay.

Chứa dữ liệu

Hằng & biến

let tenApp = "SnapEdit"
// tenApp = "X"  ❌ không đổi được

let = hằng, gán một lần.

var diem = 0
diem = 10   // ✅ đổi được

var = biến, đổi được.

Quy tắc: dùng let trước, chỉ chuyển var khi thật sự cần đổi — code an toàn & rõ ý hơn.

Bốn kiểu nền

Kiểu cơ bản

let tuoi: Int = 25          // số nguyên
let gia: Double = 19.99      // số thực
let ten: String = "An"       // chuỗi chữ
let daBat: Bool = true      // đúng/sai

Int đếm số nguyên; Double cho số lẻ; String cho chữ; Bool chỉ có true/false.

Đỡ phải gõ

Swift tự đoán kiểu

let tuoi = 25        // Swift hiểu là Int
let ten = "An"       // Swift hiểu là String

// Chỉ ghi kiểu khi cần rõ ràng:
let gia: Double = 20  // khai báo Double; 20 thành 20.0

Thường bạn không cần ghi kiểu — Swift tự suy ra từ giá trị. Chỉ ghi khi muốn rõ hoặc ép một kiểu khác.

Ghép chuỗi

Chèn giá trị vào chuỗi

let ten = "An"
let tuoi = 25

let cau = "Xin chào \(ten), \(tuoi) tuổi!"
// → "Xin chào An, 25 tuổi!"

\(...) thả giá trị bất kỳ vào giữa chuỗi. Bạn đã thấy nó ở Bài 1 — giờ thì hiểu rõ.

Gói việc làm

Hàm với func

func chao(ten: String) -> String {
    return "Xin chào, \(ten)!"
}

let loi = chao(ten: "An")   // "Xin chào, An!"

Cấu trúc: func tên(tham số: Kiểu) -> KiểuTrảVề { ... }. -> cho biết hàm trả về gì; bỏ đi nếu hàm không trả gì.

Tham số gọn & rõ

Nhãn & giá trị mặc định

func cong(_ a: Int, _ b: Int = 0) -> Int {
    a + b              // hàm 1 dòng: bỏ được "return"
}

cong(2, 3)   // 5
cong(2)      // 2  (b mặc định = 0)

_ = bỏ nhãn khi gọi. = 0 = giá trị mặc định. Hàm chỉ một dòng có thể bỏ return.

Code hoàn chỉnh

Chạy trong Playground ✅

// Dán vào Swift Playground để xem kết quả in ra
func tinhBMI(canNang: Double, chieuCao: Double) -> Double {
    canNang / (chieuCao * chieuCao)
}

let bmi = tinhBMI(canNang: 60, chieuCao: 1.7)
let ket = "BMI của bạn là \(bmi)"
print(ket)   // BMI của bạn là 20.76...

Lưu ý: nền tảng ngôn ngữ chạy trong Playground (không cần SwiftUI). Mở Xcode → File → New → Playground.
