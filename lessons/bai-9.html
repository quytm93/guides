Giải pháp: tách phần "logic" ra một nơi riêng. Đó là tư tưởng của MVVM.

Ba vai trò

M · V · VM là gì?

🧱

Model

Dữ liệu thuần — struct Post (Bài 7).

🖼

View

Giao diện SwiftUI — chỉ hiển thị và nhận thao tác.

🧠

ViewModel

Bộ não — giữ dữ liệu & logic (tải mạng, xử lý lỗi).

Luồng: View nhờ ViewModel làm việc → ViewModel cập nhật dữ liệu → View tự vẽ lại. View không còn dính tới mạng.

Công cụ

Lớp quan sát được: @Observable

Đánh dấu một class bằng @Observable — SwiftUI sẽ theo dõi và tự vẽ lại khi dữ liệu bên trong đổi:

@Observable
class PostViewModel {
    var posts: [Post] = []     // đổi → View cập nhật
}

Giống @State nhưng cho cả một "bộ não" dùng chung. Đây là class (không phải struct) vì ta cần một thứ tồn tại lâu và chia sẻ được. Cần iOS 17+ (framework Observation, đi kèm SwiftUI).

Dọn dẹp

Đưa logic vào ViewModel

@Observable
class PostViewModel {
    var posts: [Post] = []
    var dangTai = false
    var loi: String? = nil

    func tai() async {
        dangTai = true
        defer { dangTai = false }   // luôn tắt khi xong
        let url = URL(string: ".../posts")!
        do {
            let (data, resp) = try await URLSession.shared.data(from: url)
            guard let http = resp as? HTTPURLResponse,
                  (200..<300).contains(http.statusCode) else {
                loi = "Lỗi máy chủ"; return
            }
            posts = try JSONDecoder().decode([Post].self, from: data)
        } catch { loi = "Không tải được dữ liệu" }
    }
}

Toàn bộ logic Bài 8 chuyển vào đây. View sẽ "nhẹ" hẳn.

View gọn lại

Dùng ViewModel trong View

struct PostScreen: View {
    @State private var vm = PostViewModel()

    var body: some View {
        List(vm.posts) { post in
            Text(post.title)
        }
        .task { await vm.tai() }
    }
}

Với @Observable mới (iOS 17+), dùng @State để View "sở hữu" ViewModel — @StateObject là của cách cũ (ObservableObject, Bài 12). View chỉ còn: hiện vm.posts và nhờ vm.tai(). Sạch sẽ!

Trạng thái

Hiện "đang tải" & lỗi

Nhờ dangTai và loi trong ViewModel, View phản ánh đúng tình huống:

if vm.dangTai {
    ProgressView("Đang tải…")
} else if let loi = vm.loi {
    Text(loi).foregroundStyle(.red)
} else {
    List(vm.posts) { Text($0.title) }
}

ProgressView là vòng xoay "đang tải" có sẵn của SwiftUI. Ba nhánh: đang tải → lỗi → dữ liệu.

Lợi ích của MVVM

✅ Được gì

  • View ngắn gọn, dễ đọc
  • Logic tập trung một chỗ, dễ sửa
  • Dễ kiểm thử ViewModel riêng
  • Tái dùng cùng VM cho nhiều View

💡 Quy tắc

  • View: chỉ hiển thị
  • ViewModel: giữ dữ liệu & logic
  • Model: dữ liệu thuần

Với app nhỏ có thể chưa cần; nhưng càng lớn, MVVM càng giúp code không "rối như tơ vò".

Code hoàn chỉnh

Chép là chạy ✅

import SwiftUI

struct Post: Identifiable, Codable {
    let id: Int
    let title: String
}

@Observable
class PostViewModel {
    var posts: [Post] = []
    var dangTai = false
    var loi: String?

    func tai() async {
        dangTai = true; loi = nil
        defer { dangTai = false }
        let url = URL(string:
            "https://jsonplaceholder.typicode.com/posts")!
        do {
            let (data, resp) = try await URLSession.shared.data(from: url)
            guard let http = resp as? HTTPURLResponse,
                  (200..<300).contains(http.statusCode) else {
                loi = "Lỗi máy chủ"; return
            }
            posts = try JSONDecoder().decode([Post].self, from: data)
        } catch { loi = "Không tải được dữ liệu" }
    }
}

// View hiển thị thuần — dễ xem trước bằng mock
struct PostList: View {
    let posts: [Post]
    var body: some View {
        List(posts) { post in Text(post.title) }
    }
}

struct PostScreen: View {
    @State private var vm = PostViewModel()
    var body: some View {
        NavigationStack {
            Group {
                if vm.dangTai { ProgressView("Đang tải…") }
                else if let loi = vm.loi { Text(loi).foregroundStyle(.red) }
                else { PostList(posts: vm.posts) }
            }
            .navigationTitle("Bài viết")
            .task { await vm.tai() }
        }
    }
}

#Preview {
    PostList(posts: [
        Post(id: 1, title: "Bài mẫu A"),   // 👈 mock data
        Post(id: 2, title: "Bài mẫu B"),
    ])
}
