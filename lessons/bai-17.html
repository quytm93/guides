Vòng đời ứng dụng

App luôn chuyển giữa các trạng thái — đang dùng, đang chuyển, chạy nền. Biết phản ứng đúng lúc để lưu dữ liệu & tiết kiệm pin.

Bài 17 ScenePhase · Lifecycle ~25 phút
Nhấn → hoặc Space để bắt đầu
Trong bài này

Bạn sẽ học được gì

  • Các trạng thái của app: active / inactive / background
  • Điểm khởi đầu: @main App + Scene
  • Đọc trạng thái với ScenePhase
  • Lưu dữ liệu đúng lúc app vào nền
  • Vòng đời View & cầu nối AppDelegate khi cần

Cần biết @AppStorage (Bài 6) & onChange (Bài 6). Nhắm iOS 17+.

Bức tranh

Ba trạng thái của app

🟢

active

Đang ở trước mặt, người dùng tương tác bình thường.

🟡

inactive

Đang chuyển tiếp — vd có cuộc gọi đến, kéo Control Center.

⚫️

background

Bị đẩy ra nền (bấm Home, mở app khác). Sắp có thể bị "ngủ".

Lúc vào background là thời điểm vàng để lưu dữ liệu — vì hệ thống có thể tắt app bất cứ lúc nào sau đó.

Điểm khởi đầu

@main App + Scene

Mỗi app bắt đầu từ một struct tuân theo App (bạn đã gặp ở Bài 10):

@main
struct MyApp: App {
    var body: some Scene {
        WindowGroup {
            ContentView()
        }
    }
}

Scene là "khung cửa sổ" chứa giao diện. Vòng đời (active/background) gắn với Scene này.

Đọc trạng thái

Theo dõi với ScenePhase

@Environment(\.scenePhase) private var phase

Text("Trạng thái hiện tại")
    .onAppear { print(phase) }   // .active / .inactive / .background

@Environment(\.scenePhase) cho bạn trạng thái hiện tại của Scene, tự cập nhật khi nó đổi.

Phản ứng

Lưu khi app vào nền

.onChange(of: phase) { _, moi in
    if moi == .background {
        luuDuLieu()      // lưu trước khi app có thể bị tắt
    }
}

onChange (Bài 6) bắt thời điểm trạng thái đổi. Vào .background → lưu ngay. Đây là thói quen quan trọng của app thật.

Đừng nhầm

Vòng đời App vs vòng đời View

📱 Vòng đời App

  • ScenePhase: active / background
  • Cho toàn bộ app

🖼 Vòng đời View

  • onAppear / onDisappear
  • .task (Bài 8) — chạy khi view hiện
  • Cho từng màn hình riêng

App vào nền ≠ View biến mất. Dùng đúng cấp: lưu toàn cục → ScenePhase; nạp dữ liệu màn hình → .task/onAppear.

Khi cần móc cũ

Cầu nối AppDelegate

Một số việc (vd nhận device token cho Push — Bài 15) cần hook cũ của UIKit. Gắn qua adaptor:

@main
struct MyApp: App {
    @UIApplicationDelegateAdaptor(AppDelegate.self)
    var delegate
    ...
}

Người mới hiếm khi cần ngay. Cứ biết: khi một API chỉ có ở AppDelegate, đây là cách "cắm" nó vào app SwiftUI.

Code hoàn chỉnh

Ghi chú tự lưu khi vào nền — chép là chạy ✅

import SwiftUI

struct NoteView: View {
    @Environment(\.scenePhase) private var phase
    @State private var nhap = ""
    @AppStorage("ghiChuDaLuu") private var daLuu = ""

    var body: some View {
        VStack(spacing: 16) {
            TextField("Nhập ghi chú…", text: $nhap, axis: .vertical)
                .textFieldStyle(.roundedBorder)
            Text("Đã lưu: \(daLuu)")
                .foregroundStyle(.secondary)
        }
        .padding()
        .onAppear { nhap = daLuu }              // khôi phục bản nháp
        .onChange(of: phase) { _, moi in
            if moi == .background { daLuu = nhap }  // lưu khi vào nền
        }
    }
}

#Preview {
    NoteView()
}

Gõ ghi chú → bấm Home (vào nền) → mở lại: bản nháp vẫn còn. Thử trên Simulator bằng phím tắt Cmd+Shift+H.

Cùng ôn lại

Những gì bạn đã biết

  • App có 3 trạng thái: active · inactive · background
  • @main App + Scene là điểm khởi đầu
  • @Environment(\.scenePhase) để đọc trạng thái
  • onChange(of: phase) → lưu khi vào .background
  • Phân biệt vòng đời App (ScenePhase) vs View (onAppear/.task)

Lưu đúng lúc vào nền = không bao giờ mất dữ liệu người dùng. Một dấu hiệu của app chuyên nghiệp.
