Nền tảng bộ nhớ

struct vs class · stack vs heap

Trước khi soi triệu chứng: một lựa chọn nền tảng quyết định tốc độ & bộ nhớ — kiểu giá trị hay tham chiếu, nằm ở stack hay heap.

📦

struct · giá trị

Thường ở stack · sao chép khi gán · cấp phát/thu hồi gần như tức thì · không tốn ARC.

🔗

class · tham chiếu

Ở heap · chia sẻ tham chiếu · ARC đếm & thu hồi · mỗi lần cấp phát/đếm đều tốn CPU.

📌 Vì sao vào Phần 3: heap + ARC là gốc của rò rỉ & ngốn bộ nhớ (retain cycle), bị Jetsam giết (peak RAM), và CPU/pin (cấp phát thừa). Mặc định struct; dùng class khi cần chia sẻ trạng thái (ViewModel) hoặc identity. Nói gần đúng cho dễ nhớ: struct quá lớn, chứa kiểu tham chiếu, hay bị "bắt" trong closure escaping vẫn có thể lên heap; Array/String dùng Copy-on-Write.

🔴 Crash — app văng

Lỗi làm app văng ngay

  • Force-unwrap nil (!) — Dùng if let/guard let/??; tránh ! & try!.
  • Index ngoài mảng — Kiểm tra indices.contains, dùng first/last.
  • Cập nhật UI ngoài main thread — Đưa cập nhật UI về @MainActor.
  • Data race (đọc/ghi đồng thời) — Dùng actor/serial queue; bật strict concurrency.
  • try! / as! / fatalError — Dùng try?/do-catch, as?.

🔍 Phát hiện bằng: Crash log (Xcode Organizer), Main Thread Checker, Thread Sanitizer.

⚫ Bị hệ thống giết (terminations)

App bị iOS giết, không phải crash code

  • Watchdog 0x8badf00d — Không chặn main thread ở các mốc vòng đời; việc nặng làm async.
  • 0xdead10cc (giữ lock khi vào nền) — Đóng/giải phóng lock & hoàn tất ghi trước khi vào nền; xin background task.
  • Jetsam (hết RAM) — Giảm peak memory (xem nhóm Bộ nhớ): downsample, cache có hạn.
  • CPU cao khi ở nền — Dừng việc khi vào nền; dùng background task đúng cách.

🔍 Phát hiện bằng: Xcode Organizer › Terminations, MetricKit exit reasons.

🟠 Rò rỉ & ngốn bộ nhớ

Bộ nhớ phình & rò rỉ

  • Retain cycle (self giữ nhau) — [weak self] trong closure; weak/unowned cho delegate/parent.
  • Closure trong Task/Combine/timer giữ self mạnh — [weak self]; hủy Task/cancellable.
  • Ảnh load full-resolution — Downsample về đúng kích thước hiển thị trước khi vẽ.
  • Cache không giới hạn — Dùng NSCache + giới hạn số lượng/dung lượng.
  • Giữ dữ liệu lớn trong RAM — Phân trang, stream, giải phóng khi rời màn hình.

🔍 Phát hiện bằng: Memory Graph Debugger, Instruments › Leaks / Allocations.

🟡 Treo UI (hangs)

UI đứng hình

  • Việc nặng trên main thread — Đẩy việc nặng sang background; main chỉ làm UI.
  • I/O mạng/đĩa đồng bộ trên main — async/await; đọc file/mạng off-main.
  • Giải mã ảnh lớn trên main — Decode off-main; prepareForDisplay.
  • body SwiftUI làm việc nặng — Giữ body nhẹ; đừng tạo DateFormatter trong body.
  • Tác vụ đồng bộ dài trong nút bấm — Bọc Task { }, hiện ProgressView.

🔍 Phát hiện bằng: Instruments › Hangs; Xcode Organizer › Hangs (hang rate).

🟤 Giật khung hình (hitches)

Cuộn & animation rớt frame

  • Offscreen rendering — Đặt shadowPath; tránh mask; dùng cornerCurve.
  • Decode/scale ảnh trong cell khi cuộn — Decode & downsample off-main, cache sẵn.
  • Overdraw / blending — Đặt nền opaque; giảm lớp mờ.
  • Auto Layout phức tạp trong cell — Đơn giản layout; cache chiều cao; ô tự dựng.
  • Hitch rate cao — Đo & hạ hitch rate ở màn hình cuộn chính.

🔍 Phát hiện bằng: Instruments › Animation Hitches; overlay Offscreen-Rendered / Blended Layers.

🔵 CPU, pin & nhiệt

Nóng máy & tụt pin

  • Vẽ lại thừa (body churn) — Thu hẹp state; tách view nhỏ; @Observable đúng phạm vi.
  • Timer/loop chạy quá dày — Giảm tần suất; dừng khi không cần.
  • Polling thay vì event — Dùng push / async stream / callback.
  • Location accuracy cao luôn bật — Giảm accuracy; significant-change; tắt khi nền.
  • Bỏ qua nhiệt & Low Power Mode — Theo dõi ProcessInfo.thermalState & isLowPowerModeEnabled, giảm tải.

🔍 Phát hiện bằng: Instruments › Time Profiler & Energy Log; ProcessInfo.thermalState.

💾 Đĩa & I/O

Ghi đĩa quá nhiều

  • Ghi đĩa quá mức — Gộp/giảm ghi; chỉ ghi khi cần.
  • Log/analytics ghi liên tục — Throttle/batch log; tắt log nặng ở Release.
  • Core Data/SwiftData autosave churn — Batch thay đổi; lưu theo lô.
  • Ghi file lớn đồng bộ — Ghi nền, theo khối (chunk).

🔍 Phát hiện bằng: MetricKit (disk write exception), Instruments › File Activity.

🌐 Mạng

Tải dữ liệu lãng phí

  • Request lẻ tẻ liên tục — Batch & gộp request; tải trước hợp lý.
  • Không nén / payload lớn — Nén (gzip), ảnh đúng size, chỉ lấy field cần.
  • Không dùng cache (URLCache) — Bật HTTP cache; ETag/If-None-Match.
  • Không timeout / không cancel — Đặt timeout; hủy Task khi view đóng.
  • Polling thay vì push — Dùng push / long-poll / socket khi hợp lý.

🔍 Phát hiện bằng: Instruments › Network; Energy Log (networking).

🟣 Khởi động (launch)

Mở app chậm

  • Nhiều việc lúc launch — Trì hoãn việc không cần; làm lười; nền hóa.
  • init View/Model nặng — Đưa việc nặng vào .task/onAppear.
  • Đọc/giải mã dữ liệu lớn đồng bộ khi mở — Async + placeholder trước.
  • Quá nhiều dynamic framework — Giảm phụ thuộc; cân nhắc static link.

🔍 Phát hiện bằng: Instruments › App Launch; Xcode Organizer › Launches.

🟢 Concurrency (Swift 6)

Đa luồng & dữ liệu an toàn

  • Thiếu @MainActor cho UI state — Đánh dấu @MainActor cho ViewModel/UI.
  • Sai actor isolation — Thiết kế theo actor; tuân thủ Sendable.
  • Không cancel Task khi view biến mất — Dùng .task (tự hủy) hoặc cancel().
  • Chia sẻ mutable state giữa task — Bọc trong actor; tránh biến toàn cục mutable.

🔍 Phát hiện bằng: Thread Sanitizer; cảnh báo strict concurrency của trình biên dịch.

Phát hiện sớm & đo lường

Bộ công cụ săn lỗi

  • Xcode Organizer — 7 nhóm số liệu máy thật: Launches · Hangs · Hitches · Memory · Disk · Battery · Terminations
  • MetricKit — MXHangDiagnostic · MXDiskWriteExceptionDiagnostic · MXCPUExceptionDiagnostic · hitch · exit reasons
  • Instruments — Time Profiler · Allocations/Leaks · Animation Hitches · Hangs · Energy Log · Core Animation
  • Main Thread Checker — bắt cập nhật UI sai thread (bật khi Debug)
  • Thread / Address Sanitizer — bắt data race & truy cập bộ nhớ hỏng
  • Memory Graph Debugger — tìm retain cycle (đối tượng không giải phóng)
  • Debug overlays — Color Offscreen-Rendered Yellow · Color Blended Layers (soi hitch)
  • ProcessInfo — thermalState · isLowPowerModeEnabled để thích ứng

📏 Ngưỡng đáng nhớ — hang >250ms · hitch rate <5 / 5–10 / >10 ms/s · disk >1GB/ngày. Theo dõi máy thật bằng MetricKit + Xcode Organizer.
