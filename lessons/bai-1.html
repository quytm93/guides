Bạn sẽ học được gì

  • Lập trình iOS thực ra là gì
  • Những công cụ bạn cần — và giá của chúng (tin vui: bắt đầu hết 0đ)

Đừng lo phải học thuộc lòng. Mục tiêu hôm nay là cảm thấy thoải mái, chứ không phải trở thành chuyên gia.

Bức tranh tổng thể

Vậy… lập trình iOS là gì?

Đó là nghề tạo ra các ứng dụng chạy trên thiết bị Apple — iPhone, iPad và những "người bạn" của chúng.

📱

Ứng dụng

Thứ người dùng chạm, vuốt, cuộn. Ảnh, game, ngân hàng — tất cả đều là app.

🧠

Đoạn code

Những chỉ dẫn bạn viết, nói cho app biết nó trông ra sao và hoạt động thế nào.

🍎

Nền tảng

Hệ điều hành của Apple (iOS) chạy app và kết nối nó với thiết bị.

Bạn viết code → công cụ của Apple biến nó thành app → app chạy trên điện thoại. Đó là toàn bộ vòng lặp.

Bộ đồ nghề

Bạn cần gì để bắt đầu

✅ Bắt buộc

  • Một chiếc Mac — app iOS chỉ có thể tạo trên macOS
  • Xcode 26 — app miễn phí của Apple để làm app
  • Sự tò mò & kiên nhẫn — nhiên liệu thật sự

🕓 Sau này (tùy chọn)

  • Một chiếc iPhone — để chạy thử trên máy thật
  • Tài khoản Apple Developer — 99$/năm, chỉ cần khi đưa app lên App Store

Bạn có thể làm và chạy app thật ngay hôm nay chỉ với một chiếc Mac và Xcode 26 — hoàn toàn miễn phí.

Ngôn ngữ

Làm quen với Swift

Swift là ngôn ngữ lập trình bạn dùng để làm app iOS. Apple thiết kế nó vừa mạnh mẽ vừa thân thiện với người mới.

Nó đọc gần như tiếng Anh. Đây là một chương trình Swift hoàn chỉnh:

// Dòng code Swift đầu tiên của bạn
let ten = "lập trình viên iOS tương lai"
print("Xin chào, \(ten)!")

Phần \(ten) chèn giá trị của ten thẳng vào câu chữ. Kết quả: Xin chào, lập trình viên iOS tương lai!

Swift căn bản

Hai từ bạn sẽ dùng suốt

// Một chiếc hộp có thể đổi
var diem = 0
diem = 10   // ✅ được phép

var = biến. Giá trị của nó có thể thay đổi theo thời gian.

// Một chiếc hộp cố định
let pi = 3.14
pi = 3      // ❌ lỗi!

let = hằng số. Gán một lần, không bao giờ đổi.

Mẹo: cứ dùng let trước. Chỉ chuyển sang var khi bạn thật sự cần thay đổi giá trị.

Xưởng làm việc

Làm quen với Xcode 26

Xcode 26 là app miễn phí nơi bạn viết code, thiết kế màn hình và chạy app. Cả xưởng làm việc gói gọn trong một cửa sổ.

✍️

Trình soạn thảo

Nơi bạn gõ code Swift.

▶️

Simulator

Một chiếc iPhone "ảo" ngay trên màn hình để thử app — không cần máy thật.

🎨

Canvas

Bản xem trước trực tiếp của màn hình khi bạn đang dựng.

Tải miễn phí từ Mac App Store — tìm "Xcode" và cài đặt. File khá nặng, nên hãy tải sớm nhé!

Thực hành

Màn hình đầu tiên với SwiftUI

App iOS hiện đại dùng SwiftUI để mô tả màn hình. Bạn nói muốn gì, nó hiện ra:

import SwiftUI

struct WelcomeView: View {
    var body: some View {
        VStack {
            Text("👋 Chào iOS!")
                .font(.largeTitle)
            Text("App đầu tiên của mình")
                .foregroundStyle(.secondary)
        }
    }
}

VStack xếp các view theo chiều dọc. Mỗi Text là một dòng trên màn hình. Đó là một màn hình iOS thật sự!

Quy trình

Từ code đến app đang chạy

  1. 1
    Viết code Swift trong trình soạn thảo của Xcode.
  2. 2
    Nhấn ▶︎ (Run) — hoặc ⌘ + R.
  3. 3
    Xcode biên dịch (build) code thành app.
  4. 4
    Simulator khởi động và hiện app của bạn.
  5. 5
    Bạn thấy nó chạy, chỉnh code, rồi chạy lại. 🔁

Vòng lặp chặt chẽ viết → chạy → xem này là nhịp tim của việc làm app. Bạn sẽ làm nó hàng nghìn lần.

Cùng ôn lại

Những gì bạn đã biết

  • Lập trình iOS = làm app cho thiết bị Apple
  • Bạn cần một chiếc Mac + Xcode 26 (đều miễn phí để bắt đầu)
  • Swift là ngôn ngữ; let và var giữ giá trị
  • Xcode 26 là trình soạn thảo, simulator và canvas của bạn
  • SwiftUI mô tả màn hình; nhấn ▶︎ để chạy

Code hoàn chỉnh

Chép là chạy ✅

Dán nguyên đoạn này vào ContentView.swift trong Xcode 26 và bấm ▶︎:

import SwiftUI

struct WelcomeView: View {
    var body: some View {
        VStack(spacing: 12) {
            Text("👋 Chào iOS!")
                .font(.largeTitle)
            Text("App đầu tiên của mình")
                .foregroundStyle(.secondary)
        }
    }
}

#Preview {
    WelcomeView()
}

#Preview cho phép xem ngay trong Canvas mà không cần chạy Simulator. Lưu ý: project mới chạy ContentView — muốn thấy app này khi bấm Run, đổi tên WelcomeView thành ContentView (hoặc dán vào ContentView.swift).
