Lưu trữ với SwiftData

Một cơ sở dữ liệu thật ngay trong app: lưu danh sách lớn, truy vấn tự động, và giữ dữ liệu mãi mãi.

Bạn sẽ học được gì

  • Vì sao @AppStorage (Bài 6) không đủ cho dữ liệu lớn
  • Biến model thành thứ lưu được với @Model
  • Bật cơ sở dữ liệu bằng .modelContainer
  • Đọc dữ liệu tự động với @Query
  • Thêm / xoá qua modelContext

Cần xong Bài 6 & 7. SwiftData dùng lại ý tưởng "model + danh sách" của Bài 7, nhưng lưu xuống đĩa thật.

Vấn đề

Khi dữ liệu lớn dần lên

🗒 @AppStorage (Bài 6)

  • Hợp thiết lập nhỏ: bật/tắt, tên, số
  • Không hợp danh sách dài, dữ liệu phức tạp

🗄 SwiftData

  • Một cơ sở dữ liệu thật sự
  • Lưu hàng nghìn mục, truy vấn nhanh
  • Tự lưu & khôi phục qua các lần mở app

Quy tắc: thiết lập nhỏ → @AppStorage; danh sách dữ liệu thật → SwiftData.

Tổng quan

SwiftData hoạt động ra sao?

🧱

@Model

Đánh dấu lớp dữ liệu để SwiftData biết cách lưu nó.

🗄

Container

"Kho chứa" cơ sở dữ liệu, bật một lần ở App.

🔎

@Query

Tự đọc dữ liệu & cập nhật View khi có thay đổi.

Bạn chỉ mô tả dữ liệu trông như thế nào — SwiftData lo phần lưu, đọc, ghi xuống đĩa.

Mô tả dữ liệu

Model lưu được với @Model

Đổi struct (Bài 7) thành class gắn @Model:

import SwiftData

@Model
class Viec {
    var ten: String
    var xong: Bool

    init(ten: String, xong: Bool = false) {
        self.ten = ten
        self.xong = xong
    }
}

@Model biến mỗi Viec thành một "hàng" trong cơ sở dữ liệu. Cần init để tạo mục mới.

Bật cơ sở dữ liệu

Thiết lập .modelContainer

Gắn một lần ở điểm khởi đầu của app (file …App.swift):

@main
struct MyApp: App {
    var body: some Scene {
        WindowGroup {
            ViecListView()
        }
        .modelContainer(for: Viec.self)
    }
}

Dòng .modelContainer(for:) tạo & mở kho dữ liệu cho cả app. Chỉ cần làm một lần.

Đọc dữ liệu

Tự động đọc với @Query

struct ViecListView: View {
    @Query private var danhSach: [Viec]

    var body: some View {
        List(danhSach) { viec in
            Text(viec.ten)
        }
    }
}

@Query tự lấy toàn bộ Viec từ database, và tự cập nhật View mỗi khi dữ liệu thêm/xoá. Không cần tự tải!

Thêm & xoá

Ghi dữ liệu qua modelContext

@Environment(\.modelContext) private var context

// Thêm một mục mới:
context.insert(Viec(ten: "Việc mới"))

// Xoá một mục:
context.delete(viec)

modelContext là "tay ghi" vào database. SwiftData tự lưu — bạn không cần gọi save(). @Query sẽ tự cập nhật danh sách.

To-do lưu vĩnh viễn — chép là chạy ✅

import SwiftUI
import SwiftData

@Model
class Viec {
    var ten: String
    var xong: Bool
    init(ten: String, xong: Bool = false) {
        self.ten = ten; self.xong = xong
    }
}

struct ViecListView: View {
    @Query private var danhSach: [Viec]
    @Environment(\.modelContext) private var context

    var body: some View {
        NavigationStack {
            List {
                ForEach(danhSach) { viec in
                    Text(viec.ten)
                }
                .onDelete { indexes in
                    for i in indexes { context.delete(danhSach[i]) }
                }
            }
            .navigationTitle("Việc cần làm")
            .toolbar {
                Button("Thêm") {
                    context.insert(Viec(ten: "Việc mới"))
                }
            }
        }
    }
}

#Preview {
    // Container tạm trong RAM + vài mục mock để xem trước
    let kho = try! ModelContainer(
        for: Viec.self,
        configurations: .init(isStoredInMemoryOnly: true))
    kho.mainContext.insert(Viec(ten: "Học SwiftData", xong: true))
    kho.mainContext.insert(Viec(ten: "Tập thể dục"))
    return ViecListView().modelContainer(kho)
}
Cùng ôn lại

Những gì bạn đã biết

  • @AppStorage cho dữ liệu nhỏ; SwiftData cho danh sách lớn
  • @Model class mô tả dữ liệu lưu được
  • .modelContainer(for:) bật database (một lần ở App)
  • @Query tự đọc & cập nhật danh sách
  • modelContext.insert / delete để ghi; SwiftData tự lưu

Preview dùng container trong RAM (isStoredInMemoryOnly) + dữ liệu mock để xem trước nhanh, không đụng dữ liệu thật.
