Vấn đề

Một app, một ngôn ngữ?

Nếu chữ bị "gõ cứng" tiếng Việt khắp nơi, làm sao một người dùng ở Mỹ đọc được?

Text("Chào mừng bạn!")   // chỉ tiếng Việt 😢

Ta cần tách chữ ra một nơi riêng, dịch sang nhiều thứ tiếng, để iOS tự chọn theo cài đặt ngôn ngữ của máy.

Công cụ Xcode 26

Gặp gỡ String Catalog

Một tệp .xcstrings gom tất cả chuỗi của app để dịch ở một chỗ:

  1. 1
    File → New → File → chọn String Catalog (đặt tên Localizable).
  2. 2
    Build app — Xcode tự gom mọi Text("…") vào catalog.
  3. 3
    Bấm dấu + để thêm ngôn ngữ (vd English).
  4. 4
    Gõ bản dịch vào từng dòng — xong!

String Catalog là cách hiện đại (Xcode 15+), thay cho file .strings cũ. Trực quan như một bảng tính.

Điều kỳ diệu

Text("…") tự dịch được

Chuỗi bạn đưa vào Text thực ra là một LocalizedStringKey — tức "khoá để tra bản dịch".

Text("Chào mừng bạn!")
// → iOS tra trong catalog, hiện đúng ngôn ngữ máy

Hầu hết text trong SwiftUI tự localizable. Chuỗi gốc tiếng Việt vừa là "khoá" vừa là bản tiếng Việt mặc định. ⚠️ Cạm bẫy: chỉ chuỗi viết thẳng (literal) mới tự dịch — Text(bienString) (truyền một biến String) sẽ không được dịch.

Chuỗi có biến

Dịch chuỗi có nội suy

let ten = "An"
Text("Xin chào, \(ten)!")

Trong catalog, phần biến hiện thành placeholder:

VI:  Xin chào, %@!
EN:  Hello, %@!

%@ là "chỗ trống" cho giá trị. Người dịch giữ nguyên %@, chỉ đổi chữ xung quanh — kể cả đảo vị trí cũng được.

Số nhiều

Một hay nhiều?

Nhiều ngôn ngữ đổi chữ theo số lượng. Tiếng Anh: "1 item" vs "5 items".

Text("^[\(soLuong) item](inflect: true)")
// 1 → "1 item",  5 → "5 items"

String Catalog có mục Plural riêng để khai báo dạng số ít/số nhiều cho từng ngôn ngữ. Người mới chỉ cần biết nó tồn tại.

Xem trước

Thử nhiều ngôn ngữ ngay trong Preview

Ép một locale vào môi trường để xem app ở ngôn ngữ khác — không cần đổi máy:

#Preview("Tiếng Việt") {
    GreetingView(ten: "An")
        .environment(\.locale, .init(identifier: "vi"))
}

#Preview("English") {
    GreetingView(ten: "An")
        .environment(\.locale, .init(identifier: "en"))
}

Cũng có thể đổi ngôn ngữ chạy thật trong Scheme → Run → Options → App Language.

Code hoàn chỉnh

Màn hình chào đa ngôn ngữ — chép là chạy ✅

import SwiftUI

struct GreetingView: View {
    let ten: String

    var body: some View {
        VStack(spacing: 12) {
            Text("Chào mừng bạn!")        // tự localizable
                .font(.largeTitle).bold()
            Text("Xin chào, \(ten)!")       // có nội suy %@
                .foregroundStyle(.secondary)
        }
        .padding()
    }
}

// Hai preview = hai "ngôn ngữ giả" để so sánh
#Preview("Tiếng Việt") {
    GreetingView(ten: "An")
        .environment(\.locale, .init(identifier: "vi"))
}

#Preview("English") {
    GreetingView(ten: "An")
        .environment(\.locale, .init(identifier: "en"))
}

Sau khi tạo String Catalog & thêm bản dịch English, preview "English" sẽ hiện đúng tiếng Anh.

Cùng ôn lại

Những gì bạn đã biết

  • Chuỗi gõ cứng khó dịch → tách ra String Catalog (.xcstrings)
  • Text("…") là LocalizedStringKey → tự tra bản dịch
  • Xcode tự gom chuỗi; bấm + thêm ngôn ngữ rồi dịch
  • Biến nội suy hiện thành placeholder %@ cho người dịch
  • Xem trước nhiều ngôn ngữ với .environment(\.locale, …)
