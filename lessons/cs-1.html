Slide 1 · Tổng quan

Ứng dụng & mô hình

Người dùng chạm một nút, AI lo phần khó; chất lượng ảnh xuất ra là thước đo.

🌐 Lĩnh vực (domain)

  • Công cụ sáng tạo ảnh — xóa vật thể, làm nét, upscale, đổi nền.
  • Yếu tố then chốt: Chất lượng ảnh xuất ra, tốc độ xử lý, chi phí GPU server.

💰 Mô hình kinh doanh

  • Subscription (tuần/năm), bản free có watermark; paywall onboarding là đòn bẩy chuyển đổi số 1.
Slide 2 · Khái niệm & thuật ngữ

Từ khóa kỹ thuật cần biết

  • Core Image / Metal — pipeline lọc ảnh real-time trên GPU.
  • Core ML / Vision — model trên thiết bị: segmentation, super-resolution.
  • On-device vs Server — đánh đổi độ trễ ↔ chi phí ↔ riêng tư cho từng tính năng.
  • Tiling & downsampling — ảnh 48MP dễ vượt RAM → chia ô, xem trước ở độ phân giải thấp, chỉ xử lý full-res khi export.
  • StoreKit 2 — quản lý subscription, restore, trạng thái entitlement.

Thực hành · Dự án mẫu

📦 Tải về & chạy thử: PhotoEditorDemo

Một photo editor on-device chạy ngay trên Simulator — không cần server, API key hay tài khoản. Minh họa đúng cạm bẫy bộ nhớ · hang · CPU của CS-1.

🧪 Memory Lab

  • Tạo ảnh tới 48MP rồi so sánh cách SAI (full-res, main thread → đứng hình, +~190 MB) với cách ĐÚNG (downsample, off-main → mượt).
  • Đo bộ nhớ thật bằng phys_footprint ngay trên màn hình.

🏗️ Kiến trúc

  • iOS 17+ · SwiftUI · @Observable MVVM · async/await · service tách protocol.
  • Mở Xcode 16+ → ⌘R. Files dùng synchronized folders.
