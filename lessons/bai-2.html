Cài đặt & làm quen Xcode 26

Hướng dẫn thực hành từng bước: cài Xcode, tạo project đầu tiên, đi một vòng giao diện, và chạy app trên Simulator.

Nhấn → hoặc Space để bắt đầu
Mục tiêu hôm nay

Cuối bài này bạn sẽ…

  • Cài Xcode 26 lên máy Mac
  • Tạo một project iOS mới đúng cách
  • Hiểu 5 khu vực chính trong cửa sổ Xcode
  • Chạy app trên Simulator bằng nút ▶︎
  • Dùng Preview trực tiếp ngay khi gõ code

Đây là bài "tay chân" nhất khóa học. Hãy mở Mac lên và làm theo từng bước nhé!

Trước khi cài

Máy bạn cần gì?

✅ Yêu cầu

  • Một chiếc máy Mac (MacBook, iMac, Mac mini…)
  • macOS đủ mới (Xcode 26 cần phiên bản macOS gần nhất)
  • Còn trống khoảng 40 GB ổ cứng

💡 Mẹo

  • Cập nhật macOS trước: Apple menu → System Settings → General → Software Update
  • Cắm sạc & dùng Wi-Fi khỏe — file tải khá nặng

Chưa có Mac? Bạn vẫn xem hết bài để hiểu quy trình, rồi thực hành sau khi mượn/được dùng máy Mac.

Bước 1 · Chọn bản

Chọn đúng bản cho máy bạn

  • Máy Apple Silicon (M1, M2, M3, M2 Pro…) → tải bản "Xcode (Apple Silicon)". Máy Intel cũ → bản "Xcode" thường.
  • Không chắc máy chip gì? Mở menu → About This Mac để xem.
  • Cập nhật macOS lên bản mới nhất nếu được — để cài được Xcode mới. Bản Xcode cũ hơn vẫn dùng tốt, nhưng đừng quá cũ.
  • Cần Swift khác? Đổi phiên bản Swift mục tiêu của project trong Build Settings.

Muốn thử bản mới hơn bản Release? Dùng bản RC (Release Candidate) — gần như bản cuối: https://xcodereleases.com/?q=RC

Bước 2

Tạo project iOS mới

  1. 1
    Ở màn hình chào mừng, chọn Create New Project…
  2. 2
    Tab iOS → chọn mẫu App → bấm Next.
  3. 3
    Product Name: gõ ví dụ HelloiOS.
  4. 4
    Đảm bảo Interface = SwiftUI, Language = Swift.
  5. 5
    Bấm Next, chọn thư mục lưu → Create.
  6. 6
    Chọn project ở Navigator → tab General → đặt Minimum Deployments = iOS 17.0.

Các ô như "Organization Identifier" cứ để mặc định cũng được. Ta sẽ tìm hiểu sau. Đặt iOS 17.0 để dùng được các tính năng SwiftUI hiện đại như @Observable (Bài 9, 12, 16, 17).

File đầu tiên

Mở ContentView.swift

Trong Navigator (cột trái), bấm vào ContentView.swift. Bạn sẽ thấy đúng đoạn code kiểu này — Xcode tạo sẵn:

import SwiftUI

struct ContentView: View {
    var body: some View {
        VStack {
            Image(systemName: "globe")
            Text("Hello, world!")
        }
    }
}

Trông quen chứ? Đây chính là VStack + Text bạn đã gặp ở Bài 1. Bên phải, Canvas đang vẽ nó ra cho bạn xem.

Bước 4

Chạy app trên Simulator

  1. 1
    Trên Toolbar, bấm chỗ chọn thiết bị → chọn ví dụ iPhone 17.
  2. 2
    Bấm nút ▶︎ Run (hoặc nhấn ⌘ + R).
  3. 3
    Đợi Xcode build — lần đầu hơi lâu.
  4. 4
    Simulator (iPhone ảo) mở lên và chạy app của bạn. 🎉

Muốn dừng? Bấm nút ◼︎ Stop hoặc ⌘ + . (dấu chấm).

Hai cách "xem app"

Preview & Simulator khác gì?

🎨 Preview (Canvas)

  • Ở ngay trong Xcode, cột phải
  • Cập nhật tức thì khi bạn gõ
  • Tuyệt cho việc chỉnh giao diện nhanh

📱 Simulator

  • Một app iPhone "ảo" riêng
  • Chạy app thật sự, bấm/vuốt được
  • Dùng để thử toàn bộ app như người dùng

Nếu Preview hiện chữ "Preview paused", bấm nút ↻ Resume (hoặc ⌥ + ⌘ + P) để bật lại.

Thử ngay

Sửa thử một dòng

Đổi chữ trong Text và xem Canvas đổi theo ngay lập tức:

VStack {
    Image(systemName: "swift")   // đổi icon
    Text("Xin chào, mình đang học iOS!")
}

Vừa gõ xong, Preview bên phải đã đổi. Đây là vòng lặp sửa → thấy ngay giúp bạn học rất nhanh.

Code hoàn chỉnh

Chép là chạy ✅

Đây là ContentView.swift sau khi bạn sửa thử ở Bước trên — dán vào Xcode 26 và bấm ▶︎:

import SwiftUI

struct ContentView: View {
    var body: some View {
        VStack(spacing: 12) {
            Image(systemName: "swift")
                .font(.largeTitle)
                .foregroundStyle(.orange)
            Text("Xin chào, mình đang học iOS!")
        }
        .padding()
    }
}

#Preview {
    ContentView()
}

Thấy Canvas đổi theo ngay khi gõ là môi trường của bạn đã chạy đúng. 🎉
